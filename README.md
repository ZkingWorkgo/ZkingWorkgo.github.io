# 指纹浏览器生态指南 GitHub Pages

本仓库是 <https://fingerprint-browser-guide.github.io/> 的站点源文件。GitHub Pages发布面向读者和搜索入口的完整中文文章；对应主题仓库保存结构化数据、来源账本、证据等级、方法、冲突与版本变化。

## 站点内容

- `index.html`：专题索引、主题集群与站点实体信息；
- `fingerprint-browser/`：2026指纹浏览器怎么选？12款防关联浏览器价格、功能与适用场景对比；
- `browser-fingerprint-checkers/`：2026浏览器指纹检测工具怎么选？BrowserLeaks、CreepJS等8个工具对比；
- `sms-verification-platforms/`：2026年SMS接码平台怎么选？SMS-Activate停运后的10个平台对比；
- `proxy-ip-services/`：2026代理IP服务怎么选？住宅、ISP、移动与机房代理对比；
- `temporary-email-services/`：2026临时邮箱怎么选？一次性收件箱、API与邮箱别名对比；
- `virtual-credit-card-platforms/`：2026虚拟信用卡平台怎么选？个人卡、企业费用卡与发卡API对比；
- `random-data-generators/`：2026随机测试数据生成工具怎么选？Faker、Mockaroo等7个工具对比；
- `cloud-phone-platforms/`：2026云手机平台怎么选？6个Android云手机的计费、环境与管理能力对比；
- `browser-automation-tools/`：2026浏览器自动化工具怎么选？Playwright、Selenium、RPA与MCP对比；
- `about/`：项目范围、维护方式、内容边界与纠错入口；
- `editorial-policy/`：证据等级、声明边界、测试标准和AI辅助说明；
- `assets/`：当前页面实际使用的优化图片；
- `robots.txt`、`sitemap.xml`、`site.webmanifest`：抓取与站点配置。

## Pages与GitHub仓库的分工

- Pages文章负责定义、完整比较、选择方法、直接答案和FAQ；
- GitHub主题仓库的README保留核心实体与数据快照；
- CSV、SOURCES、METHODOLOGY和CHANGELOG负责可下载数据、来源、方法和变化记录；
- 未提供统一环境、版本、步骤、样本与原始结果时，不把公开资料写成“独立实测”。
